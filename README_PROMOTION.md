# 板読みリプレイ / Trade Analysis Tool プロモーションページ

## 公開ページ

ブラウザで見られる商品紹介ページです。板読みリプレイの特徴、他の一般的な使い方との比較、実際の操作ボタンの見た目、操作方法、検証の流れを広告・チラシ風にまとめています。商品紹介TOPと実際に触るソフトウェアDEMOは別HTML・別階層です。

公開時は `promo.html`、`promo.css`、`promo-sales.css`、`promo-nintendo.css` を同じフォルダへ配置してください。TOPはNintendo.com 2001年頃のY2Kハードウェア感を参考に、オリジナルのクローム・パネル、カーボンドット、シグナルカラー、走査光・浮遊・ホバー演出で構成しています。現在のDEMOリンクは次の公開先を指しています。

- 商品紹介TOP：`/boardreadtools/`（`index.html`）
- ソフトウェアDEMO：`/boardreadtools/software/`（`index.html`）
- 旧DEMO互換URL：`/boardreadtools-demo/`

## メインメッセージ

> 日本株の板読み情報をインポートして、板読みをゆっくり巻き戻す、早送りする、止める。同じ場面を何度でも繰り返して検証できるトレード分析ツール。

## ページで説明している機能

- JSONL GZIPの複数ファイル読込
- 注文CSVから「約定済・新規」をENTRY合図として表示
- `Z / X` の戻る・進む
- `A / S` の5倍戻る・5倍進む
- ▶再生による自動リプレイ
- 板、歩み値、価格チャートの同じTick同期
- 価格帯別の約定出来高・約定件数
- 板から消えた価格の「価格別約定履歴（過去ログ）」
- 水平線、レイ、RR計測、Entry／LC／TP、矢印などの検証メモ
- 板表示本数、現在値固定、クロスライン、板の高さなどの設定

## 使い方の案内

1. 「本日のDEMOを触ってみる」からDEMOを開く。
2. GZIPと注文CSVが自動読込されるまで待つ。
3. 初期表示の6976（太陽誘電）で、Z/XまたはA/Sを押して前後へ移動する。
4. ▶再生で板・歩み値・チャートを同時に動かす。
5. 銘柄選択で7974（任天堂）へ切り替え、同じように検証する。

商品紹介TOPには、一般的な価格チャート、ライブ注文板、静止画・手作業の振り返りと比較したセールストークを掲載しています。個別の他社製品を名指しせず、用途の違いとして説明できる構成です。

ページは印刷用CSSにも対応しているため、ブラウザの印刷機能でチラシ風の資料として出力できます。
