# 板読みTools 共通GZIPリプレイAPP

銘柄ごとの巨大なHTMLを毎回生成せず、`jsonl.gz` を読み込んで板読み検証を行うための土台です。

## 板読みの見方：板の偏りだけで決めない

板の数量は、その瞬間に表示されている注文です。注文の取消や追加、買い注文による売り板の吸収で、板の見た目とその後の価格は変わります。売り板が厚くても価格が上がることがあるため、板だけで「下がる」とは断定できません。

今回の例の **−52.3%** は、売数量が買数量より多いという板の偏りです。板では一般に売り注文が上段、買い注文が下段に並び、売数量を左、価格を中央、買数量を右に表示します。LONGを考える場面では、歩み値で売り注文が実際に約定しているか、その後も価格を維持できたかを確認します。

- 板：その時点で出ている注文
- 歩み値：約定した取引
- 確認すること：売り板を吸収したか、価格を維持したか、次の値動きはどうか

日誌のENTRY価格 **8,948円** と板画像の現在値 **8,940円** は、約定時刻「09:15:00」が分単位で記録され、板画像には最も近い観測データが使われたため、完全に同じ瞬間の価格ではありません。

## できること

- `.jsonl.gz` / `.gz` をファイル選択からストリーム展開。複数選択した場合は、同じ銘柄のTick・板履歴を時刻順に結合
- GZIP内の複数銘柄を検出し、銘柄を切り替え
- `compact.current_price` を時間足（標準15秒足、任意入力可）に集計してローソク足・出来高を表示
- 検証起点はAPIの `OpeningPriceTime`（9:03・9:06などの実際の寄り付き時刻を含む）を優先し、ない場合は9:00以降の最初の有効Tickを使用。始値をオレンジ色の破線、VWAPを補助線として描画
- APIの `OpeningPrice` がある場合、最初の時間足のO（始値）にも同じ価格を採用し、H/L/Cはその足の実Tickから集計。API始値がない場合だけ9:00以降の最初の有効TickをOにする
- 検証カーソルより未来の足は描画せず、チャート・出来高・板・右側の歩み値を同じTickに同期
- `Z` / `X` またはボタンで前後へ移動。標準の移動幅は100 Tickで、`A` / `S` または「5倍戻る／進む」ボタンはその5倍（500 Tick）です。スライダーも残す
- 価格チャートの出来高バーにカーソルを合わせると、その足の出来高（株数）と約定Tick数を表示
- 板の各価格帯に、現在Tickまでのその価格での約定出来高・約定件数と、現在板の板数量・板件数を分けて表示。約定件数は約定レコードの回数であり参加者数そのものではない。約定出来高÷約定件数の平均数量も各セルの説明で確認可能。板件数は元データに含まれる注文件数だけを表示し、数量や約定件数からは推測しない。板件数列は標準の「自動」設定で、件数フィールドがない入力では列ごと非表示にする
- 板の表示を4種類から切替。レイアウト1は板型「売件数／売数量／価格／買数量／買件数」、レイアウト2は価格帯分析「価格／約定出来高／約定件数／板数量／板件数」、レイアウト3は現在板と過去ログを高値→安値へ統合した価格順表示（標準）、レイアウト4は約定出来高の大きい価格から確認する約定分析。注文件数フィールド（`Count` / `OrderCount` など）がデータにある場合だけ板件数へ表示し、ない場合は `-` とする
- レイアウト3では、価格ごとの累積約定出来高を横棒（価格帯出来高バー）で可視化。バーは表示中の最大約定出来高を100%とする相対表示で、上部の「価格帯出来高バー」または設定画面からON／OFFを切替可能
- チャート側の価格帯別約定出来高は、現在表示中の価格チャート左側へ価格軸に沿って重ねて表示できる。レイアウト5はレイアウト3の価格順板と組み合わせて確認するパターンで、板内バーとチャート側バーは設定画面でそれぞれON／OFF・色・透過率を個別に変更可能
- 価格帯出来高バーはキーボードでも切替可能。標準は `B` で板内バー、`V` でチャート左側バーをON／OFFし、設定画面で英数字1文字へ変更可能（`Z` / `X` / `A` / `S` はリプレイ操作用のため予約）
- `Enter` で時間足入力を開き、`15S` / `30S` / `1` / `2` / `30` / `D` などを入力して切替
- TradingView風の軸操作: 下の時間軸をホイール・横ドラッグで拡大縮小。標準では最新価格が右端に残るため、最新部分をそのまま拡大できます。設定からマウス位置基準にも変更可能です。クリックで全時間表示、左の価格軸のホイール・上下ドラッグで価格を拡大縮小、クリックで全価格表示
- 時間軸は複数の時刻目盛りを表示し、クロスラインは標準ON。設定または上部の「クロスライン」で表示／非表示を切替
- 始値はオレンジ色、水平線と右向きレイはそれぞれの設定色で、同じ呼値の板価格行を上下の境界線・色付きラベルとして連動。チャートの現在値に自動表示していた黄色の垂直カーソルは表示しない
- 水平線の標準色は黄色、右向きレイの標準色は水色点線。上部の線色または設定画面から銘柄検証中の色を変更可能
- 15秒足の検証開始時は右側に9:30までの時間余白を確保。検証カーソルが進んだときは時間軸も価格軸も標準で追随し、設定から価格軸だけ「追随しない（固定）」へ変更可能
- `raw.Sell1..Sell10` / `raw.Buy1..Buy10` を現在板として表示し、標準40本で仮説ゾーンを追加
- 大口板のバッジ、大きな約定の歩み値強調と画面フラッシュ
- 水平線、右向きレイ、RR（Entry / LC / TP）、矢印、消去・全消去、Cursor表示
- RR計測時はENTRYを基準にLC・TPまでのPIPS（価格差）と呼値数をチャートへ表示し、ENTRY / LC / TPの各価格帯を対応色で板にも連動表示
- データはHTMLへ埋め込まず、読み込み中の端末メモリだけを使用
- 板・歩み値は上部の操作パネル直下から表示し、標準で画面高の92%まで拡張（設定から48〜100%へ変更可）
- 歩み値の横幅は従来より約10%拡張
- 注文CSVの「約定済・新規」だけを読み込み、約定単価・時刻・買い／売り・数量をチャート上のENTRY合図として表示。リプレイカーソル到達前の合図は表示しない
- 注文件数が収録された板データは、`OrderCount` / `OrderNum` / `OrderNumber` / `Count` / `Num` / `Orders` / `order` / `o` などの価格別フィールドを読み込み、現在価格の上下10本にもその値を表示。標準の「自動」設定では、KabuステーションAPIログなど元データに件数がない場合は板件数列ごと非表示にする。「常に表示」にした場合だけ`-`を表示して欠損を確認できる
- 上部コントロールとサマリーはコンパクト表示が標準。設定から標準密度へ戻せます。コントロールはスクロール時も上端に残ります
- 呼値は価格帯別に表示。TOPIX500、ETF等（1口）、その他の内国株を自動判定し、設定で銘柄ごとに手動登録も可能

## Mac APPのビルド

```sh
cd "/Users/th/Documents/板読みTools/boardreadtools-app"
./build-mac-app.sh
open "./BoardReadTools.app"
```

Mac APPのサイズはHTML生成物のようにGZIPデータを内包しません。GZIPは起動後に選択します。
複数GZIPを選ぶときは、前場・後場のファイルを同時に選択してください。重なりがあっても時刻順に表示します。

## 呼値

- 太陽誘電（6976）は登録済みのTOPIX500テーブルを使い、10,000円台では **5円** 刻みです。
- トヨタ自動車（7203）は同テーブルを使い、2,000〜3,000円台では **0.5円** 刻みです。
- 適用テーブルはサマリーと板読みヘッダーに表示します。構成銘柄の入替や特殊商品は、`設定 → 呼値テーブル` から対象銘柄だけ上書きできます。

呼値の価格帯表はJPX公式の[内国株の呼値の単位](https://www.jpx.co.jp/equities/trading/domestic/07.html)に基づいています。TOPIX500の構成変更で適用対象が変わるため、APP内では上書き設定を残しています。

## データ上の注意

- GZIPのCRCエラーや展開失敗は警告を表示し、失敗したファイルの途中までのデータは破棄します。正常なGZIPの始値・ローソク足へ混入させません。個別のJSON行破損はその行をスキップして警告します。
- `ORDERS` が空の記録でも、価格変化がある `PUSH` から歩み値を作れます。
- 同一銘柄の切り替えは、読み込んだGZIPの範囲内で行います。銘柄別HTMLは生成しません。
- 仮説ゾーンは直近1 / 3 / 5分に観測された外側板を再分類して表示する検証補助です。取得間隔中の取消・更新は確定できません。
